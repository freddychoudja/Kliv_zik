# Kliv Mobile (React Native CLI)

Version mobile de Kliv créée avec React Native CLI.

## Lancer le projet

```bash
cd /tmp/workspace/freddychoudja/Kliv_zik/mobile
npm install
npm run android
```

## Build APK Android (debug)

```bash
cd /tmp/workspace/freddychoudja/Kliv_zik/mobile/android
./gradlew assembleDebug
```

APK attendu:

`/tmp/workspace/freddychoudja/Kliv_zik/mobile/android/app/build/outputs/apk/debug/app-debug.apk`
